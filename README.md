# 名合 貴洋｜ソフトウェアエンジニア

C++によるデスクトップアプリケーション・画像処理の開発と、Laravel・Reactを用いたWebアプリケーション開発に取り組んでいます。

実務では産業機器の制御ソフトウェアや外観検査システムの開発を経験。課題の把握から設計・実装・テストまで、一貫して対応できることが強みです。

個人開発では、C++の画像処理技術とWeb技術の連携、AI APIを活用したアプリケーションの設計・開発にも取り組んでいます。

## 技術スタック

- **言語：** C++, PHP, JavaScript, TypeScript, Python
- **フレームワーク・ライブラリ：** Laravel, React, OpenCV
- **デスクトップ・Web技術：** Tauri, WebAssembly
- **開発環境・ツール：** Linux, Docker, CMake, Git, GitHub

## 実務経験

- C/C++による産業機器の制御プログラム開発・機能改修
- C++による画像処理を用いた外観検査システムの開発
- Tauriを用いたデスクトップアプリケーションの開発
- 要件・課題の把握から設計、実装、テストまでの一貫した開発
- Linux、Dockerを用いた開発環境での業務経験

## 個人開発

### [SVG App](https://github.com/TakahiroNago/svg-app) / [SVG変換デモ](https://svg.art-full-stack.com/)

C++・OpenCVによるラスター画像からSVGへの変換ツールです。

- C++による画像解析・減色・輪郭抽出・SVG生成
- CLIと変換コアを分離した設計
- WebAssemblyを介したブラウザ上での変換処理
- React・TypeScriptによるWebインターフェース

### [PaintMix](https://github.com/TakahiroNago/paint-mix-app) / [Webアプリ](https://paint.art-full-stack.com/)

- ReactによるUIの設計・実装
- TypeScriptによる型を活用した開発
- ブラウザ上で利用できるWebアプリケーションの公開

### [ZEN App](https://github.com/TakahiroNago/zen-app) / [Webアプリ](https://zen.art-full-stack.com/ja)
